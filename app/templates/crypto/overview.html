How coins are analysed

Every coin runs through three independent analyses. Each check scores from -1 to +1, weighted, and each pillar maps to 0-100 (50 = neutral).

  • Tokenomics ({{ (weights.fundamental * 100) | int }}%): a coin has no earnings, so its fundamentals are market-cap size, liquidity (3-month average volume / market cap), dilution overhang (fully diluted value / market cap), supply cap, measured supply inflation, track record (years since launch), distance from the all-time high, and whether it is a meme coin.
  • Technical ({{ (weights.technical * 100) | int }}%): 200-day trend, moving-average stack, golden/death cross, ADX, Supertrend, RSI, MACD, Stochastic, Bollinger %B, on-balance volume, volume surges, relative strength vs Bitcoin. Same code as the stock pages, on a 365-day year.
  • Chart ({{ (weights.chart * 100) | int }}%): swing structure, 60-day regression channel, 52-week breakouts, support/resistance, Bollinger squeeze, pullback setups, double tops/bottoms, candlesticks, RSI divergence.

Technicals weigh more than for stocks because coins are driven by momentum and flows far more than by "value". Buy needs composite ≥ {{ gates.Buy.composite }}, tokenomics ≥ {{ gates.Buy.fundamental }}, technical ≥ {{ gates.Buy.technical }}, chart ≥ {{ gates.Buy.chart }}, reward/risk ≥ {{ gates.Buy.reward_risk }} and no hard red flag ({{ hard_flags | join(', ') | lower }}).

Not covered (no free, reliable source here): on-chain activity (active addresses, fees, exchange flows), developer activity, token-unlock calendars, staking yields, exchange and regulatory news.
